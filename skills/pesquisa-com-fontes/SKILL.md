# Pesquisa com fontes

## 1. Defina a pergunta

Reescreva o pedido como 1 pergunta principal e 3 a 6 subperguntas. Defina o recorte: período, país, público, orçamento. Se o pedido for ambíguo, faça uma pergunta rápida antes de começar.

## 2. Busque com amplitude

- Faça várias buscas com termos diferentes, incluindo em inglês quando o assunto for global.
- Priorize fontes primárias: documentação oficial, artigos científicos, dados de governo, relatórios da própria empresa, anúncios oficiais.
- Use fontes secundárias (imprensa, blogs especializados) para contexto e para achar as primárias.
- Desconfie de: conteúdo patrocinado, páginas sem data, listas de "top 10" sem metodologia, informação citada sem fonte.
- Verifique a data de cada fonte. Para tecnologia, preços e IA, informação com mais de 6 meses pode estar desatualizada.

## 3. Cheque cruzado

- Fatos importantes precisam de pelo menos 2 fontes independentes.
- Quando as fontes discordarem, mostre as versões e explique qual parece mais confiável e por quê.
- Separe claramente **fato verificado**, **estimativa** e **opinião**.

## 4. Escreva o relatório

```markdown
# [Pergunta]

## Resposta curta
3 a 5 frases que respondem à pergunta principal.

## Detalhes
Uma seção por subpergunta, com citações no texto [1], [2].

## Comparativo (quando fizer sentido)
Tabela com os critérios que importam para o usuário.

## Limitações
O que não foi possível confirmar, dados desatualizados, vieses das fontes.

## Fontes
[1] Título — site — data — URL
```

## Regras

- Cada número, data e citação precisa ter fonte.
- Nunca invente URLs ou títulos. Se não encontrou, diga que não encontrou.
- Seja direto na recomendação quando o usuário pedir uma escolha.
